# かきくらべ

日本語フォントを一覧で見比べるための、1枚で動くWebページです。iPadのブラウザでの利用を想定しています。

**開く：** https://follllly.github.io/kakikurabe/

## できること

- 入力した文を、Google Fontsの日本語書体（69書体すべて）と同梱のPixelMplusで一覧表示
- 3つの表示：**一覧**／**吹き出し**／**参考**
- 分類で絞り込み、書体名で検索、★お気に入り。書体名を押すと、利用条件・配布元へのリンク・名前のコピーをまとめた画面が開く
- **太さの切り替え**（100〜900）。偽の太字は作らない
- **吹き出し**：ふつう・叫び・心の声・ナレーションの4つの形、しっぽの向き（なし・左下・右下・左上・右上）、中央ぞろえ／天揃え、1行の最大文字数、吹き出しの大きさを固定して文字だけ変える（入りきらないと赤で表示）
- **組み合わせ（自作アンチゴチ）**：かなと漢字・英数を別々の書体で表示
- **入っていない字の印**：参考表示で、書体にない字のマスを赤枠で示す
- **参考**：入力した字（空白を除いて最大60字）をマス目と十字の補助線つきで表示、★の書体を半透明で重ねる表示
- **フォントを追加**：ダウンロードした .ttf / .otf / .woff / .woff2 をブラウザ内に保存。分類と利用条件のメモも付けられる
- **★の書き出し・読み込み**：別の端末・ブラウザへ移す
- 吹き出し表示では背景が漫画の原稿用紙のような方眼になる
- iPadのホーム画面に追加すると、アプリのように開ける

★・追加したフォントは、使っているブラウザの中だけに保存されます。

## メモ

- Google Fontsの書体はページを開いたときに読み込みます。読み込めなかった書体には「読み込めませんでした」と出ます。
- 書体に入っていない字は、別の書体で代わりに表示されます。
- フリーフォントを作品に使うときは、配布ページの利用条件を確かめてください。

## 同梱フォント

- `fonts/pixelmplus/` — PixelMplus（itouhiro）。M+ FONTSライセンス（改変・再配布・商用利用可）。ライセンス文は同じフォルダにあります。

## フォントの扱い（再配布について）

- **Google Fontsの書体**：このリポジトリには入れていません。ページを開いたときに、Googleのサーバーから直接読み込んでいます。
- **自分で追加したフォント**：使っている端末のブラウザの中だけに保存されます。GitHubには送られません。
- **同梱するフォント**：配布条件で再配布がはっきり許されているものだけを、ライセンス文と一緒に置きます（現在はPixelMplusのみ）。
- **おすすめのフリーフォント**：配布元へのリンクだけを載せています。
