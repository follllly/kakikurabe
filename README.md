# 書体見本帳

日本語フォントを一覧で見比べるための、1枚で動くWebページです。iPadのブラウザでの利用を想定しています。

**開く：** https://follllly.github.io/shotai-mihoncho/

## できること

- 入力した文を、Google Fontsの日本語書体（69書体すべて）と同梱のPixelMplusで一覧表示
- 分類（ゴシック・明朝・丸ゴシック・アンチック・手書き風・筆・ポップなど）で絞り込み、書体名で検索
- ★お気に入り（ずっと取っておく）と、ピン留め（いま比べている候補を一番上に固定）
- **吹き出し**：ふつう・叫び・心の声・ナレーションの4つの形に流し込んで表示（縦書き／横書き）
- **太さの切り替え**：100〜900。書体が持っていない太さのときは「その太さはなし」と表示し、偽の太字は作らない
- 縦書き・白黒反転・文字の大きさの切り替え
- **手書き参考**：文の最初の6文字を、マス目と十字の補助線つきで大きく表示
- **重ね表示**：★とピンの書体を半透明で重ね、どの書体にも共通する骨組みを見る
- **フォントを追加**：ダウンロードした .ttf / .otf / .woff / .woff2 を読み込み、ブラウザ内に保存。分類と利用条件のメモも付けられる
- フリーフォントの配布・検索サイトへのリンク集

★・ピン・追加したフォントは、使っているブラウザの中だけに保存されます。

## メモ

- Google Fontsの書体はページを開いたときに読み込みます。読み込めなかった書体には「読み込めませんでした」と出ます。
- 書体に入っていない字は、別の書体で代わりに表示されます。
- フリーフォントを作品に使うときは、配布ページの利用条件を確かめてください。

## 同梱フォント

- `fonts/pixelmplus/` — PixelMplus（itouhiro）。M+ FONTSライセンス（改変・再配布・商用利用可）。ライセンス文は同じフォルダにあります。

## フォントの扱い（再配布について）

- **Google Fontsの書体**：このリポジトリには入れていません。ページを開いたときに、Googleのサーバーから直接読み込んでいます。
- **自分で追加したフォント**：使っている端末のブラウザの中だけに保存されます。GitHubには送られません。
- **同梱するフォント**：配布条件で再配布がはっきり許されているものだけを、ライセンス文と一緒に置きます（現在はPixelMplusのみ）。
- **おすすめのフリーフォント**：配布元へのリンクだけを載せています。
